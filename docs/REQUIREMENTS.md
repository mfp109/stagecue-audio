# StageCue Audio 要件定義

作成日: 2026-06-24

## 1. 目的

StageCue Audio は、イベント・礼拝・発表会・学校行事で、音楽や効果音を安全に再生するための日本語アプリです。

QLab の「キューを並べて GO で進める」考え方を参考にしつつ、音楽再生に絞り、英語UIと一時停止まわりの分かりにくさを解消します。

## 2. 参考にする QLab の考え方

QLab 5 は、ライブメディア再生とショーコントロールのためのアプリで、基本単位は cue です。cue は開始されると1つの動作を実行し、cue list は上から下に進む直線的な再生構造です。

StageCue Audio では、この考え方を次のように取り入れます。

| QLab の考え方 | StageCue Audio での扱い |
|---|---|
| Cue | 曲・効果音・停止・一時停止・フェードなどの「本番動作」 |
| Cue List | イベントごとのセットリスト |
| GO | 次のキューを実行する大きな本番ボタン |
| Playhead | 次に鳴るキューの位置 |
| Audio Cue | 音声ファイルを鳴らすキュー |
| Pause / Stop / Fade | 日本語で明確に分けた安全操作 |

## 3. 対象ユーザー

- イベントで音楽を流すスタッフ
- 礼拝や学校行事の音響担当
- 発表会や小規模舞台の担当者
- QLab は便利だが、英語UIと操作のクセで本番使用が不安な人

専門の音響エンジニアだけでなく、当日だけ担当する人でも扱えることを重視します。

## 3.1 初期方針

- 最初は Mac 版を作る。
- Mac 版が実用できる状態になったら、GitHub で一般公開する。
- 初期用途はイベント用。
- 初期版では MIDI / OSC / Stream Deck などの外部制御は扱わない。

## 4. 最重要コンセプト

### 4.1 本番モードは迷わせない

本番画面には、次の情報を大きく表示します。

- 今鳴っている曲
- 次に鳴る曲
- 残り時間
- 現在位置
- 次の操作
- 音量

操作ボタンは次に絞ります。

- GO
- 一時停止
- 再開
- 停止
- フェードアウト停止
- 戻る
- 次へ

### 4.2 一時停止を分かりやすくする

一時停止は、次の2種類を明確に分けます。

| 操作 | 意味 |
|---|---|
| 一時停止 | 今鳴っている音をその位置で止める。再開すると同じ位置から続く。 |
| 停止 | 今鳴っている音を終わらせる。次に再生すると先頭または設定した開始位置から始まる。 |

本番中は、一時停止中のキューに「一時停止中」と大きく表示し、次に押すべきボタンを「再開」として出します。

### 4.3 フェードアウト停止を標準にする

イベントでは、急に止めるよりフェードアウトしたい場面が多いです。

そのため「停止」と別に「フェードアウト停止」を用意します。初期値は3秒にし、曲ごとに変更できます。

## 5. MVP範囲

### 5.1 セットリスト作成

- 音声ファイルを追加する。
- ドラッグ&ドロップで追加する。
- 曲順をドラッグで入れ替える。
- ステージごとにリストを作る。
- リスト単位で曲順を管理する。
- キュー名を日本語で編集する。
- メモを入れる。
- セットリストを保存・読み込みする。

### 5.2 音声キュー

各音声キューは次を設定できます。

- ファイル
- 表示名
- 音量
- ゲイン
- 開始位置
- 終了位置
- フェードイン秒数
- フェードアウト秒数
- ループする / しない
- 終了後に自動で次へ進む / 待機する
- メモ

### 5.3 本番再生

- 大きな GO ボタンで次のキューを再生する。
- Space キーで GO。
- 選択中のキューを即再生する。
- 今鳴っている音を一時停止する。
- 一時停止した音を再開する。
- 停止する。
- フェードアウト停止する。
- 次のキューへ移動する。
- 前のキューへ戻る。
- 現在位置と残り時間を表示する。
- 再生位置を指定した位置から開始する。

### 5.4 安全機能

- 本番モードでは編集操作をロックできる。
- 停止は確認なし、全停止は確認ありにする。
- 音声ファイルが見つからないキューは赤く表示する。
- 再生前に音声ファイルの存在をチェックする。
- 誤って2回GOを押したときの動作を設定できる。

### 5.5 日本語UI

画面上の主要語は日本語にします。

| 英語的な語 | 表示語 |
|---|---|
| Cue | キュー |
| Cue List | セットリスト |
| Playhead | 次に再生 |
| Target | ファイル |
| Arm | 有効 |
| Disarm | 無効 |
| Panic | 全停止 |

## 6. 画面構成

### 6.1 編集画面

- 左: ステージ別リスト
- 中央: 選択中キューの詳細
- 下: プレビュー再生
- 右: メモ・本番時の注意

編集画面では、曲の追加、順番変更、ステージ別整理、開始位置・終了位置・音量・ゲイン・フェード設定を行います。

### 6.2 本番画面

- 中央: 大きな GO ボタン
- 上: 今鳴っている曲
- その下: 次に鳴る曲
- 下: 一時停止、再開、停止、フェードアウト停止
- 右: 残り時間とメモ

本番画面では、編集項目を出しすぎません。

## 7. QLabとの差別化

| 項目 | QLab | StageCue Audio |
|---|---|---|
| 主目的 | 音声・映像・照明・外部制御まで含む総合ツール | 音楽・効果音再生に集中 |
| UI | 英語 | 日本語 |
| 操作思想 | 舞台専門家向け | イベント担当者も扱える |
| 一時停止 | cue操作として理解が必要 | 音楽アプリに近い言葉で明示 |
| 学習量 | 高機能な分、覚えることが多い | 本番操作を絞る |
| 初期対象 | Mac中心 | Mac優先、将来Windowsも検討 |

## 8. 技術方針

既存の `StageCast Video` と `StageSlide Studio` に合わせ、Electron を第一候補にします。

- 実行環境: Electron
- 音声再生: HTMLAudioElement または Web Audio API
- 保存形式: `.stagecue`
- 内部形式: `project -> cueLists -> cues`
- 配布: electron-builder
- 初期対象: Mac
- 将来対象: Windows
- 公開方針: Mac版が実用段階になったら GitHub で一般公開

音量・フェード・複数音声の同時再生が必要になるため、MVP後は Web Audio API を優先します。

```json
{
  "version": 1,
  "title": "イベント名",
  "cueLists": [
    {
      "id": "list-1",
      "name": "第1部",
      "cues": [
        {
          "id": "cue-1",
          "type": "audio",
          "number": "1",
          "name": "入場曲",
          "filePath": "/path/to/audio.wav",
          "volume": 0.85,
          "gainDb": 0,
          "startTime": 0,
          "endTime": null,
          "fadeIn": 0,
          "fadeOut": 3,
          "loop": false,
          "afterAction": "wait",
          "memo": "司会の合図でGO"

      ]
    }
  ]
}
```

## 10. MVPでやらないこと

- 映像再生
- 照明制御
- MIDI / OSC 連携
- タイムコード同期
- 複雑な自動進行
- ネットワーク越しの遠隔操作
- 多人数同時編集
- Stream Deck 連携

これらは QLab に近づきすぎるため、MVPでは扱いません。

## 11. 将来拡張

- Stream Deck 連携
- MIDI フットスイッチ対応
- 複数セットリスト
- 効果音ポン出し画面
- 自動フェード付きクロスフェード
- 音量メーター
- 外部画面に曲名や残り時間を出すステージ表示
- `StageSlide Studio` や `StageCast Video` との連携

## 12. 確定事項

1. 最初は Mac 専用で作る。
2. Mac 版ができたら GitHub で一般公開する。
3. 初期用途はイベント用。
4. 曲順再生を主目的にする。
5. 曲順の入れ替え、ステージごとのリスト、曲の再生位置指定、曲ごとのゲイン設定をMVPに含める。
6. 一時停止は同じ位置から再開する。
7. MIDI / OSC / Stream Deck などの外部制御は初期版では扱わない。

## 13. 次に決めること

1. アプリ名を `StageCue Audio` で確定するか。
2. 保存形式を `.stagecue` で確定するか。
3. ステージ別リストの例を「第1部 / 第2部 / 休憩 / エンディング」のような区切りにするか。
4. ゲイン表示を dB 表示にするか、0〜100 の分かりやすい表示にするか。
