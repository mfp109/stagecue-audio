# StageCue Audio 画面仕様

作成日: 2026-06-25

この文書は、要件メモの次段階として、仮データのフロント試作に入る前に画面仕様を固定するためのものです。

この段階では、実ファイル再生・保存処理・バックエンド実装は増やさない。まず「画面として使いやすいか」を確認する。

## 1. 画面全体の方針

StageCue Audio はイベント本番で使う音楽再生アプリなので、画面は「準備」と「本番」を分ける。

| モード | 目的 | 主な利用タイミング |
|---|---|---|
| 編集モード | ステージ、曲順、開始位置、ゲイン、メモを準備する | イベント前 |
| 本番モード | GO、一時停止、再開、停止を迷わず押す | イベント中 |

初期版では1つのアプリ画面内で、左から「ステージ」「曲リスト」「曲設定」、下部に「本番操作」を置く。

## 2. 共通ヘッダー

### 表示するもの

- イベント名
- 現在の保存状態
- 開く
- 保存
- ステージ追加
- 曲追加

### 操作

| 操作 | 動き |
|---|---|
| イベント名を編集 | セットリスト全体の名前が変わる |
| 開く | `.stagecue` ファイルを読み込む |
| 保存 | 現在のセットリストを `.stagecue` として保存する |
| ステージ追加 | 左のステージ一覧に新しいステージを追加する |
| 曲追加 | 選択中ステージに音声キューを追加する |

### 状態表示

| 状態 | 表示 |
|---|---|
| 未保存変更あり | 「未保存」 |
| 保存済み | 「保存済み」 |
| ファイル未選択 | 「新規セットリスト」 |

## 3. ステージ管理

### 目的

イベントの流れを「第1部」「第2部」「休憩」「エンディング」のように分け、ステージごとに曲順を管理する。

### 表示するもの

- ステージ名
- ステージ内の曲数
- 選択中ステージの強調表示

### 操作

| 操作 | 動き |
|---|---|
| ステージをクリック | そのステージの曲リストを表示する |
| ステージ名を編集 | ステージ名を変更する |
| ステージ追加 | 新しい空のステージを作る |
| ステージ削除 | 曲が入っている場合は確認して削除する |
| ステージ並び替え | イベント進行順を変更する |

### 確認したいこと

- ステージ名が長くても読めるか。
- 曲数が一目で分かるか。
- 今どのステージを編集しているか迷わないか。

## 4. 曲リスト

### 目的

選択中ステージの曲順を管理し、イベント当日に上から順番にGOできるようにする。

### 表示するもの

- 曲番号
- 曲名
- 開始位置
- 終了位置
- 音量
- ゲイン
- 終了後の動き
- メモ有無
- ファイル欠落状態

### 操作

| 操作 | 動き |
|---|---|
| 曲をクリック | 右側に曲設定を表示する |
| 曲をドラッグ | 曲順を入れ替える |
| 上へ / 下へ | 選択曲を1つ移動する |
| 削除 | 選択曲をリストから外す |
| 曲追加 | 選択中ステージの最後に追加する |

### 状態表示

| 状態 | 表示 |
|---|---|
| 選択中 | 背景色を変える |
| 再生中 | 再生中ラベルを付ける |
| 一時停止中 | 一時停止中ラベルを付ける |
| ファイル欠落 | 赤系で警告する |

### 確認したいこと

- 曲順がすぐ分かるか。
- 曲数が増えても見失わないか。
- ゲインや開始位置が一覧で確認できるか。
- 本番中に誤って削除しにくいか。

## 5. 曲設定パネル

### 目的

選択した曲の再生条件を細かく設定する。

### 表示するもの

- 表示名
- ファイル名
- 開始位置
- 終了位置
- 音量
- ゲイン
- フェードイン秒数
- フェードアウト秒数
- くり返し再生
- 終了後の動き
- メモ

### 操作

| 操作 | 動き |
|---|---|
| 表示名を編集 | 曲リスト上の名前も変わる |
| 開始位置を入力 | GO時にその位置から再生する |
| 終了位置を入力 | その位置で停止する |
| 音量を変更 | 曲ごとの基本音量を変える |
| ゲインを変更 | 曲ごとの増減幅をdBで変える |
| フェード秒数を変更 | フェードイン/アウトの秒数を変える |
| 終了後の動きを変更 | 待機 / 次へ進む を選ぶ |
| メモを書く | 本番中の注意として表示する |

### 入力ルール

| 項目 | 範囲 |
|---|---|
| 開始位置 | 0秒以上 |
| 終了位置 | 空欄または開始位置より後 |
| 音量 | 0〜100% |
| ゲイン | -24dB〜+12dB |
| フェード秒数 | 0秒以上 |

### 確認したいこと

- ゲインは dB 表示で分かりやすいか。
- 開始位置・終了位置は秒入力で十分か。
- 波形表示や試聴ボタンが初期版から必要か。

## 6. 本番操作バー

### 目的

イベント中に、次に押すべき操作を迷わず実行する。

### 表示するもの

- 今鳴っている曲
- 次に再生する曲
- 現在位置
- 残り時間
- GO
- 一時停止
- 再開
- 停止
- フェードアウト停止

### 操作

| 操作 | 動き |
|---|---|
| GO | 選択中の曲を設定された開始位置から再生する |
| 一時停止 | 現在位置で止める |
| 再開 | 一時停止位置から再生する |
| 停止 | 再生を止め、次回は開始位置から再生する |
| フェードアウト停止 | 設定秒数で音量を下げて停止する |

### キーボード操作

| キー | 動き |
|---|---|
| Space | GO |
| P | 一時停止 / 再開 |
| S | 停止 |
| F | フェードアウト停止 |
| ↑ / ↓ | 曲選択を移動 |

### 確認したいこと

- GOが十分大きいか。
- 一時停止と停止を間違えにくいか。
- 本番中に次の曲名がすぐ読めるか。
- 残り時間が必要十分な大きさか。

## 7. 本番モード

### 目的

イベント中は編集操作を隠し、再生操作だけに集中する。

### 表示するもの

- 今鳴っている曲
- 次に再生する曲
- 残り時間
- メモ
- 大きいGO
- 一時停止 / 再開 / 停止 / フェードアウト停止

### 隠すもの

- 曲削除
- ステージ削除
- ファイル追加
- 細かい設定入力

### 確認したいこと

- 本番モードは初期版から必要か。
- 編集モード下部の本番操作バーだけで十分か。
- 本番モード切替ボタンをどこに置くか。

## 8. 保存 / 読み込み

### 保存するもの

- イベント名
- ステージ一覧
- 曲順
- 曲ファイルのパス
- 表示名
- 開始位置
- 終了位置
- 音量
- ゲイン
- フェード秒数
- ループ設定
- 終了後の動き
- メモ

### 読み込み時の表示

| 状態 | 表示 |
|---|---|
| 正常 | そのまま表示 |
| 音声ファイルが見つからない | 曲リストに警告 |
| 形式が古い | 読み込み後に保存を促す |
| 壊れたファイル | エラー表示 |

## 9. エラー表示

### 想定エラー

- 音声ファイルが見つからない
- 音声ファイルを再生できない
- 保存できない
- 読み込めない
- 終了位置が開始位置より前
- ゲインが範囲外

### 表示方針

- 本番中に画面中央をふさがない。
- 何が起きたか短く日本語で出す。
- 次にできる操作を出す。

例:

```text
音声ファイルが見つかりません。
ファイルを選び直すか、この曲をスキップしてください。
```

## 11. 確認ゲート

仮データ試作後、次を確認してからデータ設計へ進む。

1. イベント中に迷わずGOできそうか。
2. ステージ別リストが現場の流れに合っているか。
3. 曲ごとの開始位置・ゲイン設定が分かりやすいか。
4. 一時停止と停止を間違えにくいか。
5. 本番モードが必要か。
6. ゲイン表示は dB でよいか。
7. 次にデータ設計へ進んでよいか。
