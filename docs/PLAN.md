# StageCue Audio 計画

## 目的

イベント用の音楽再生を、QLabより分かりやすい日本語UIで扱える Mac アプリを作る。

中心要件は、ステージごとに曲順を作り、GOで順番に再生し、一時停止・再開・停止・フェードアウト停止を本番中に迷わず扱えること。

## 確定方針

1. 最初は Mac 版。
2. 実用段階になったら GitHub で一般公開。
3. 初期用途はイベント。
4. 曲順再生が主目的。
5. ステージ別リスト、曲順入れ替え、開始位置、終了位置、曲ごとのゲインをMVPに含める。
6. 一時停止は同じ位置から再開。
7. MIDI / OSC / Stream Deck 連携は初期版では扱わない。

## MVP

- 音声ファイル追加
- ドラッグ&ドロップ追加
- ステージ作成
- ステージごとの曲リスト
- 曲順入れ替え
- 曲名編集
- 開始位置、終了位置、ゲイン、音量、フェード秒数の編集
- セットリスト保存/読み込み
- GO再生
- 一時停止/再開
- 停止
- フェードアウト停止
- 現在曲、次曲、残り時間表示
- 音声ファイル欠落の表示

## 技術選定

- Electron
- HTMLAudioElement を初期実装に使う
- ゲインとフェード制御が安定した段階で Web Audio API へ寄せる
- 保存形式は `.stagecue`
- アプリIDは `tech.shalomworks.stagecueaudio`
- GitHub repo 名は `stagecue-audio`
