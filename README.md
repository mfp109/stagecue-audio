# StageCue Audio

StageCue Audio は、イベントで使うための、日本語の音楽再生アプリです。

QLab のように曲や操作をキューとして並べ、本番では大きな GO ボタンと分かりやすい一時停止・再開・停止操作で安全に進行します。

## 目的

- 英語UIに迷わず使える。
- 一時停止、再開、停止、フェードアウトを本番中に間違えにくくする。
- 曲順、ステージ別リスト、音量、ゲイン、開始位置、終了位置、フェードを事前に仕込める。
- イベント当日は「次に何が鳴るか」「今何が鳴っているか」がすぐ分かる。
- 最初は Mac 版を作り、実用段階になったら GitHub で一般公開する。
